# v0.5 Standard PLC Support Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the isolated tasks and TDD.

**Goal:** Execute standard PLC blocks/operators, explicit conversions and local constants.
**Architecture:** Extend POU state for blocks, a pure operator module for overloads, and resolve
constant expressions/array types before ordinary validation. Root owns final integration.
**Tech Stack:** Python3.11+, stdlib-only runtime, pytest and Ruff.
**Spec:** docs/superpowers/specs/2026-10-27-v05-standard-design.md

## Global Constraints
- No Git repository; baseline .work/v05-standard/baseline, no commits or worktrees.
- Preserve 704 tests, virtual clock and fault policy, stable descendants, Python argument atomicity.
- Disjoint file ownership; coordinated integration after dependencies land.

## Review Focus
- SEL/MUX must not execute unselected side effects but must validate all branch types (task4).
- Constants must not escape readonly through fields, indices, FOR or output bindings (task3).
- Counter edge memory must update during reset/load and saturate at WORD bounds (task1).
- Conversions must preserve TIME categories and REAL rounding without bool-as-int (task2).
- Bound expressions must be checked before allocating composite defaults (task3).
