## Global Constraints

- Disjoint parallel ownership per developer instruction; pinned interfaces in briefs.
- Capacity 1..1_000_000, default80, standard function buffers255, Latin-1 strict.

## Review Focus
- Comments/quotes/escapes and case inside strings must survive lexing (task2).
- Capacity and NUL truncate storage consistently, but invalid Unicode never hides (task1/4).
- Conversion values are range-checked and strict; no Python Unicode-digit acceptance (task1).
- Constant capacity projection/dependencies must fail before aggregate allocation (task3).
- Different value capacities copy; IN_OUT mismatches reject without mutation (task3/4).
