# v0.14 References Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute data-reference ST code and short-circuit conditions with Python Cell bindings.

**Architecture:** Add typed non-owning ReferenceSlot over stable Cell storage with lifetime tokens.
Keep raw binding lookup distinct from dereferenced value/storage access. Reuse the native XML
loader pipeline, Python argument prevalidation and deterministic scan clock.

**Tech Stack:** Python >=3.11, stdlib runtime, pytest, Ruff, setuptools.

**Spec:** docs/superpowers/specs/2026-10-27-v014-references-design.md

## Global Constraints

- Python >=3.11, standard-library-only runtime, Linux, no installed TwinCAT.
- Preserve v0.13 behavior, checked arithmetic, Latin-1 strings, resource limits and virtual time.
- Keep failures source-aware; execution failures fault the Runtime as before, argument errors do not.
- Preserve stable Cell identity when replacing structure/array values.
- No general pointers, FB references, reference-valued returns/properties, nested references,
  reference-containing arrays/structures or aliases whose target is a reference in v0.14.
- No native TwinCAT parity claim without differential tests; document checked-profile differences.

## Review Focus

1. Replacing a parent structure/array must leave references to descendants pointing at live storage.
2. An escaping local/VAR_TEMP reference must expire; persistent VAR_INST and inherited fields survive.
3. A later invalid Python argument must not partially change earlier reference/value inputs.
4. Short-circuit skips runtime effects but does not hide type/name errors from validation.
5. Reference initialization and inherited SUPER calls must bind actual live storage, not copied maps.

### Task 2: Checked references, lifetimes, Python binding and short-circuit execution

test_runtime_references.py and test_short_circuit.py; extend loader tests for execution as needed.

lifetime token with its descendants. Existing Runtime.call/FBHandle.call/call_method/set_input
accept Cell or exact integer 0 for reference inputs. No new public constructor is required.
