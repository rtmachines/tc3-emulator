## Global Constraints

- Runtime remains standalone, Python >=3.11, standard library only, Linux usable and deterministic.
- Preserve v0.11 behavior and past examples.
- Existing expanded budgets: 10,000 nested FB instances, 1,000,000 scalar leaves; each interface slot contributes one leaf.
- No Git repository: baseline/review artifacts in .work/v012-interfaces; no Git initialization, commits or worktrees.
- User authorized implementation. Proceed through verification without another approval gate.

## Review Focus

- Interface receiver rebound during argument/RHS evaluation still calls the captured original target (Task2).
- A transient FB escapes through an interface and must become unusable after its scope ends; persistent VAR_INST must remain valid (Task2).
- Interface prototype type/default resolution cannot capture implementing FB/method/property constants (Task2).
- Narrow property contract cannot expose an extra setter or private implementation member (Task2).
- .TcIO declaration-only XML cannot inject implementation or additional objects, and strict prior importers reject leaked interfaces (Task1).
