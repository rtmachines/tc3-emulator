# v0.8 PLC execution implementation plan

> **For agentic workers:** use superpowers:subagent-driven-development and TDD.

**Goal:** Run PROGRAM/GVL with deterministic virtual PLC cycles and import .TcGVL.
**Architecture:** Frozen GVL AST, synthetic validation scopes, shared persistent Frames/Cells.
**Tech Stack:** Python>=3.11, stdlib runtime, pytest, Ruff/reviewdog.
**Spec:** docs/superpowers/specs/2026-10-27-v08-plc-design.md

## Global Constraints
- User authorized execution; no repeat approval gate. NoGit repo or commits/worktrees.
- Preserve1745baseline tests except obsolete explicit PROGRAM rejection fixtures.
- Three disjoint parallel tasks with pinned interfaces; root integration/examples/docs.
- No wallclock or sleeping; same now_ms and shared budget per full scan, advance after success.

## Review Focus
- Cross-file constant/type dependencies and cycles before allocation (task2).
- Read-only global cells cannot escape via descendants or IN_OUT (task3).
- Namespace/local shadowing identical in validator and runtime (task2/3).
- Failed cycle retains writes but neither advances time nor runs later programs (task3).
- Strict XML metadata/section boundary checks still reject hidden code (task1).
