# v0.6 Bit Support Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development and test-driven-development.

**Goal:** Execute BYTE/DWORD, based literals, bit operations, shifts/rotations and stable bit views.
**Architecture:** Shared pure bit semantics, parsed numeric BitAccess nodes and cached static
bit paths; Engine writes through parent storage. Disjoint tasks then coordinated integration.
**Tech Stack:** Python3.11+, stdlib-only runtime, pytest, Ruff.
**Spec:** docs/superpowers/specs/2026-10-27-v06-bits-design.md

## Global Constraints
- No Git repository: snapshot .work/v06-bits/baseline, no commits/worktrees.
- Preserve1048 tests and all existing runtime semantics outside explicit v0.6 additions.
- Parallel disjoint ownership: core bits, parser, validator, root execution/memory/docs.

## Review Focus
- NOT/highest-bit shifts must respect width, never Python unbounded signed NOT (task1/4).
- Source literal width must survive unary/binary/builtin return typing (task2/3/4).
- Signed owner sign bit and whole-aggregate replacement preserve other bits/aliases (task4).
- Constants remain read-only, bits cannot escape as IN_OUT, indices cannot execute code (task3/4).
- Lexer must distinguish based literals, floats, ranges and dot-bit access (task2).
